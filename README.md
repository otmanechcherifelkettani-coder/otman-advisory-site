# Otman Kettani advisory website — v2

A dependency-free static website for Otman's independent AI and operations advisory practice.

## Preview locally

```bash
python3 -m http.server 8080 --directory .
```

Open `http://localhost:8080`.

## Files

- `index.html` — page structure, copy, navigation and small menu script
- `styles.css` — responsive visual system
- `passation.md` — design, factual and publishing constraints for future work

## Before publishing

1. Otman reviews every claim and the contact details.
2. Check the site does not imply that Uber endorses the practice.
3. Replace or expand proof only with public, cleared evidence.
4. Add privacy/legal pages before adding analytics or a form.
5. Re-test at 1440, 1024, 768 and 390 px widths.

No analytics, trackers, cookies, external fonts, build step or live form are included.
